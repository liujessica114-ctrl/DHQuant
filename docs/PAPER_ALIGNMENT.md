## 待作者决定：损失归一化

式 (12)–(13) 给出输出 L1 和特征匹配损失、λ=5，以及 BasicLayer 特征，但未明确损失 reduction 和 `normalize` 的完整数值定义。

复制时的实现存在两点：

- `[B,L,C]` 特征除以 `[B,1,1,1]` 范数后成为 `[B,B,L,C]`，发生跨样本广播。
- L1/MSE 配置已经使用 `mean`，调用处再次除以元素数。

当前先保留这段历史实现，避免在作者决定前改变训练定义。可选修正是：按样本做 L2 归一化，使用 mean L1/mean MSE，不再重复除法，并为零范数加入稳定项。采用修正后需要重新验证训练和论文指标；重命名或小规模回归通过不能替代这个验证。

保留损失公式但将 batch 从 16 改为 32 也会改变训练行为：将相同样本重复组成双倍 batch 时，当前特征损失会变为原来的 1/4，输出项不变。损失定义与 batch 配置必须一起核对。

0.1.1 已将默认训练配置的 batch 恢复为历史记录的 16，并增加九份明确位宽/倍率的历史配置；没有更改历史损失公式。新训练默认 `quant.bound_policy: ordered`，在初始化/更新后修复跨越或零宽的区间；历史配置明确使用 `legacy`，不做该投影。两种训练定义不能混称为相同的历史复现。

## 待作者决定：HCG 初始化抽样

现有 HCG 对每组超过 20,000 个元素时，用 `torch.randint` 有放回抽样 20,000 个值，再对抽样后的 min/max 搜索 100 个区间。论文式 (11) 及描述未写明这层近似。

当前保留原抽样，以保持历史数值行为。作者可决定补充实现说明，或改为组内全部激活并重新验证结果。不能直接把这项差异称为已严格复现论文。

## 历史 checkpoint 与实验对应关系

九份主表权重的路径、实际加载日志和指标记录均已找到，当前文件的倍率、位宽及 SHA-256 已核对；×3、4 bit 对应 `train_2DQuant_x3_bit4_mse/models/net_Q_2900.pth`。这确认了历史日志的对应关系，不代表已用整理后的代码重新复现指标，也不能恢复当时缺失的源码版本或二进制哈希。

九组训练日志均记录 batch size 16。三组 2 bit 的预算为 10,000 次、选用 9,400 或 9,700 步权重；3/4 bit 的预算为 4,000 次、选用 1,400–3,900 步权重。×4、3/4 bit 的日志种子为 3407，其余为 2026。配置预算与实际完成步数、选用步数应分别记录。

与选定历史测试日志比较，论文主表的 90 个指标中有 89 个按保留位数相符。×2、2 bit 的 Manga109 PSNR 在日志中为 36.1670，四舍五入应为 36.17，论文为 36.16；该项尚待核实。部分重复评测日志有小幅数值差异，完整记录保留在本地审查材料中。

4 份权重存在实际使用的 HCG 分组上下界反转：×4/2 bit 为 4 组，×3/2 bit 为 20 组，×3/3 bit 为 1 组，×2/2 bit 为 20 组。0.1.1 提供显式 `legacy` 加载，原样保留这些数值；默认 `ordered` 仍拒绝反转的活动区间。空组检查已修复，未使用的 `[0,0]` 组不再阻止重载。九份历史权重在 CPU 上全部加载成功，固定单输入与修复前算术逐位一致；该对照仅在审查代码中绕过原拒绝检查，没有改动历史权重。

九份历史配置已补齐关键日志设置。迁移后的 ×3、×4 校准归档在 HR 部分被截断，但所需 LR 图块和元数据完整，通过逐记录 CRC 校验后已另存为只含 `lq` 的文件；原文件未改动，也没有生成缺失的 HR。×2 恢复结果与正常读取的原张量逐位相同。发布前仍需核实历史资产来源、在目标环境重跑完整 benchmark；公开下载地址、消融表配置与权重对应尚未完成。详见 [发布说明](RELEASE_GUIDE.md)。
